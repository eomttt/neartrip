# 수동 순서와 선택 도착점

기록일: 2026-09-11. 기존 사용자 요청과 구현을 사후 기록한 문서다. 결정의 최초 날짜를 뜻하지 않는다.

## 배경

사용자는 숙소에서 오늘 들를 곳을 직접 고르고 선택한 순서대로 동선을 만들고 싶다고 요청했다. 출발점으로 돌아오는 기존 흐름에 선택 도착점을 추가해 달라고 요청했다.

## 결정

화면에는 선택한 순서대로 동선을 만드는 행동만 제공한다. 도착점이 없으면 출발점으로 돌아오고 있으면 그곳에서 여행을 마친다. 중간 방문은 최대 5곳이며 도착점은 개수에서 제외한다.

## 결과

사용자가 정한 방문 순서가 동선과 같아진다. 장소 선택 후 더 짧은 동선을 자동으로 찾는 일은 사용자가 직접 순서를 바꾸는 일로 남는다.

## 근거

- 사용자 요청: “그냥 순서대로 동선 짜기만 있으면 될 것 같아.”
- 사용자 요청: “도착점 있으면 출발 → 도착이고 없으면 지금처럼 출발 → 출발.”
