## 다음 실행 순서

다음 구현 대상은 #7 하나다. 새 선행 작업은 없으며 기존 #3의 경로 선택을 확장한다. 의존 순환은 없다.

#7에 오류 분류·변경 파일·유지할 계약·회귀 테스트 기준을 적었다. 도보를 이미 받은 뒤 대중교통 조회가 일시적으로 실패하는 경우부터 구현한다. 이후 연결 도보 실패와 인증·설정 오류 전파를 검증한다.

이번 요청은 문서와 티켓 준비까지다. Drill의 plan·prepare는 완료로 기록하고 write·review·qa는 다음 구현을 위해 대기 상태로 둔다. 과거 구현과 테스트를 이번 Drill 실행의 완료 이력으로 소급하지 않는다.

## Drill 상태 위치

프로젝트 루트의 `neartrip.wiki/`를 문서 기준 경로인 `spec_root`로 사용한다. feature 이름은 `neartrip-mvp`이며 상태 파일은 `neartrip-mvp/.drill-state.json`이다. 별도 Wiki Git 저장소는 사용하지 않는다.

문서는 `neartrip.wiki/` 바로 아래에 두고 상대 경로로 연결한다. 상태 파일의 documents 항목에 실제 문서 경로를 기록했다. 다음 실행은 이 상태와 원격 #7을 읽고 미완료 단계부터 시작한다.
